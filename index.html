关于

半熟的代码，刚刚好的声音。

medium rare code / 半熟代码是一个独立音乐项目。作品从生活里的具体片段出发： 异乡与归途、海边与雪山、宠物、朋友，以及那些像程序变量一样不断变化的情绪。

本站收录正式发行的单曲与专辑、歌曲背景和官方音乐平台入口。你可以从下方浏览全部作品， 或选择常用平台继续收听。
